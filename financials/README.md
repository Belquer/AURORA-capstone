# Financials

**Owner:** MIP (lead) with one person from MEM and ECE · **Works with:** every area

**Goal:** know what the project spends, and what one disc costs.

## Files

- [budget.md](budget.md): capstone budget by area.
- [purchases.csv](purchases.csv): every purchase, one row each. Add a row when you order.
- [reader-cost.csv](reader-cost.csv): the reader, prototype versus a streamlined product.
- [disc-cost.csv](disc-cost.csv): the per-disc cost model. Update it when materials or
  production measure something new.

## Targets

| Item | Target |
| --- | --- |
| One disc, both sides | $5 or less |
| One reader (prototype) | about $250 incl. arm and audio |
| One reader (streamlined, 1,000+ units) | about $60–115 parts and assembly |
