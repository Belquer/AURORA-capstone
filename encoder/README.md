# Encoder (conversion software): private

The software that turns audio into a printable disc is **not in this public repo**. It
lives in a private repository with the production disc format.

What this area still does here, in public:

- **MIP:** listening tests (Opus 96 / 128 / 160 kbps against the 24-bit master) and
  mastering guidelines for the format.
- **Everyone:** request print files from Daniel. Ready-to-print test discs are in
  [`prototypes/paper-mockup/print-kit/`](../prototypes/paper-mockup/print-kit/).
- **Coupon patterns** (dot ladders) are generated privately and handed to production as
  print files following [spec/print-file.md](../spec/print-file.md).

Students who need to work on the encoder sign the project NDA and are added to the
private repository.
