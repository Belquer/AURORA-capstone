# Print file v0 (draft)

| Item | Value |
| --- | --- |
| Format | TIFF, one per side, plus a PNG preview |
| Channels | Cyan, magenta, yellow separations (no black, no white unless the blank needs a base) |
| Resolution | Native printer resolution, TBD with production (G1X lists 1440 × 2400 dpi) |
| Origin | Disc centre at the image centre, matching the centre-pin jig |
| Marks | Cut line and centre cross outside the data region, on a separate layer |
| Name | `ARTIST_TITLE_SIDE_v###.tif` |
| Metadata | Sidecar JSON: format version, cell pitch, states, capacity, encoder version |
